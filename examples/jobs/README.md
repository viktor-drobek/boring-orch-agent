# Job templates

These files are examples of the complete public task contract. Copy one into your own job directory, replace the objective and schema for the actual outcome, then submit it with a stable idempotency key.

- `read-only-review.json` — inspect a workspace and return prioritized findings.
- `inventory.json` — return a structured inventory for an API client.
- `write-summary.json` — write one named summary file; requires explicit installation and worker write permission.

Read [`docs/job-descriptions.md`](../../docs/job-descriptions.md) before adapting a template.
